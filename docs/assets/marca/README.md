# Marca do Orkastery

> **Em uma frase:** o símbolo é a órbita com a batuta em latão e os cinco naipes, seis posições
> para as seis fases da thread, e o nome usa a Fraunces do site.

Todo texto está convertido em contorno, então nenhum arquivo depende de fonte instalada.

| Pasta | O que tem | Quando usar |
| --- | --- | --- |
| `svg/` | `assinatura`, `simbolo`, `nome` e `icone`, cada um também em `-fundo-claro` | Qualquer uso novo: é a fonte de todas as outras peças |
| `png/` | As mesmas peças em PNG | Onde SVG não é aceito |
| `favicon/` | `favicon.ico` (16, 32 e 48 px), `favicon.svg`, ícone de celular, ícones do manifesto e `site.webmanifest` | Sites e páginas do projeto |
| `github/` | Avatar de 1024 px | Foto da organização no GitHub |

A prévia social do repositório fica em [`../social-preview.png`](../social-preview.png).

## Regras de uso

- **Cores:** fundo `#0a0908`, tinta `#f5f1ea` e latão `#e0b264`. No fundo claro, o latão escurece
  para `#b07f2c`.
- **Respiro:** deixe em volta da assinatura pelo menos a altura do ponto de latão.
- **Tamanho mínimo:** a assinatura a partir de 120 px de largura. Abaixo disso, use só o símbolo.
- **Favicon:** o `favicon.svg` tem os traços mais grossos de propósito, para ficar legível em
  16 e 32 px. Não use o `icone.svg` em aba de navegador.
- **Não faça:** trocar as cores, girar o símbolo, mudar a posição da batuta ou esticar o nome.
